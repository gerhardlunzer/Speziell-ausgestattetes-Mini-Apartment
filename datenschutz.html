Hosting über GitHub Pages

Diese Website wird über GitHub Pages, einen Dienst der GitHub, Inc., bereitgestellt. Beim Besuch der Website wird die IP-Adresse des Besuchers von GitHub aus Sicherheitsgründen protokolliert und gespeichert. Weitere technische Daten können im Rahmen der Bereitstellung und Absicherung des Dienstes verarbeitet werden.

Kontaktaufnahme

Wenn Sie telefonisch, per E-Mail oder über WhatsApp Kontakt aufnehmen, werden die von Ihnen übermittelten Angaben zur Bearbeitung Ihrer Anfrage und zur weiteren Kommunikation verarbeitet.

Bei einer Kontaktaufnahme über WhatsApp erfolgt die Kommunikation über den Dienst WhatsApp. Dabei gelten zusätzlich die Datenschutzbestimmungen des jeweiligen Anbieters. WhatsApp wird beim bloßen Besuch dieser Website nicht automatisch geladen; eine Verbindung entsteht erst, wenn Sie den entsprechenden WhatsApp-Link verwenden.

Google Maps

Auf dieser Website kann eine Karte von Google Maps angezeigt werden. Die Karte wird nicht automatisch beim Aufruf der Website geladen. Eine Verbindung zu Google wird erst hergestellt, wenn Sie aktiv auf „Karte anzeigen“ klicken.

Nach der Aktivierung der Karte können Daten, insbesondere Ihre IP-Adresse sowie technische Informationen über Ihr Gerät und Ihren Browser, an Google übertragen und von Google verarbeitet werden.

Weitere Informationen zur Datenverarbeitung durch Google finden Sie in der Datenschutzerklärung von Google .
